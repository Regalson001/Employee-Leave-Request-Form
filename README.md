# Employee Leave Request Form

A responsive and accessible employee leave request form built with **HTML5 and CSS3**. This project demonstrates semantic form design, native browser validation, and responsive layouts through a practical human resources use case.

## Overview

The Employee Leave Request Form provides a structured interface for employees to request annual leave, sick leave, or personal time off. It focuses on usability, accessibility, and a clean, professional user experience using core front-end technologies.

## Features

- **Semantic HTML5** — Uses `<form>`, `<fieldset>`, and `<legend>` to organize related form fields.
- **Structured Form Controls** — Supports employee information, leave categories, date selection, and additional request details.
- **Native Form Validation** — Uses HTML attributes such as `required` and appropriate input types.
- **Interactive CSS States** — Applies `:focus`, `:valid`, `:invalid`, `:checked`, and `:hover` for visual feedback.
- **Responsive Layout** — Uses CSS Flexbox to support different screen sizes.
- **Accessibility-Focused Design** — Emphasizes clear labels, logical field grouping, and visible keyboard focus.
- **Maintainable Code** — Separates HTML structure from CSS presentation.

## Scope and Limitations

This project focuses on the front-end interface. Without a connected backend or external service, it does not persist leave requests, notify managers, calculate leave balances, or manage approval workflows.

Native browser validation improves input checking but does not replace server-side validation in a production application.
